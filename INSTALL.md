# Installation

1. Create a **public** repository named `.github` under `PT-ZYNTRIX-ARTIFICIAL-INTELLIGENCE`.
2. Copy the contents of this package's `.github/` directory into that repository.
3. Ensure the default branch contains:
   - `profile/README.md`
   - `profile/assets/*.svg`
4. Open the GitHub Organization **Overview** page.
5. The organization profile README should render automatically.

The SVG assets use lightweight declarative animation and degrade gracefully to a static image.
